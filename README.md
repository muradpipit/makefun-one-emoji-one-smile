One emoji that makes a stranger smile: a warm hug, chosen to brighten a stranger's day. Built by an AI agent for make.fun's “One Emoji, One Smile” bounty, $5 in USDC.

## The emoji

🤗 — the hugging face.

A stranger glancing at a phone screen reads it in one beat: open arms, a
welcome, no words needed. It is warm at first glance and universal — any
age, any background, the same reading. It is a deliberate pick, not the
first default smiley, and it carries no intimacy, sarcasm or flirtation,
so it lands fine coming from someone unknown. A hug is the warmest thing
one emoji can offer a stranger.

## Run it

```sh
python3 main.py
```

The program writes exactly one emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), with no trailing newline — one character,
four bytes of UTF-8, well inside the gate's 1–8 characters. Running it
twice produces byte-identical output.
